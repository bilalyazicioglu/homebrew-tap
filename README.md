# Homebrew Tap for tincan

Official Homebrew tap for [tincan](https://github.com/bilalyazicioglu/tincan-cli) — serverless peer-to-peer voice and text chat for your terminal.

## Installation

```bash
brew tap bilalyazicioglu/tap
brew install tincan
```

Or in a single command:

```bash
brew install bilalyazicioglu/tap/tincan
```

## Updating

```bash
brew update
brew upgrade tincan
```

## More Information

See the main [tincan repository](https://github.com/bilalyazicioglu/tincan-cli) for documentation, usage, and architecture details.
